## Selected work

### [Pholio](https://github.com/leulenq/pholio-app)

Co-founded a talent portfolio and agency platform. I work on the AI search system, which turns natural-language casting briefs into structured requirements, retrieves candidates with pgvector embeddings and reciprocal-rank fusion, and produces source-grounded match explanations.

The system also uses consent checks before AI processing or embedding storage and removes derived search data after consent withdrawal.

### [ActinTrackCV](https://github.com/Sapkota-Lab/ActinTrackCV)

A microscopy-video analysis tool for measuring actin filament dynamics. I built the R Shiny interface, synthetic ground-truth validation harness, and next-generation tracking work.

### [Stomatal Phenotyping Pipeline](https://github.com/Sapkota-Lab/StomatalPhenotypingPipeline)

Computer vision workflow for identifying stomata in microscopy images. The pipeline uses tiled inference, spatial consensus, calibrated review tiers, and checkpointed GPU execution on UKY's SLURM cluster.

### [ActinTrackV2](https://github.com/Sapkota-Lab/ActinTrackV2)

A backend for microscopy motion tracking with calibration support, synthetic-motion tests, and exportable result bundles.
